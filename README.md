# Pratikal — Online Store

Teal-themed e-commerce store with Firebase + Paystack.

## Features
- Shop & cart (browse without login)
- Login only on Profile or Checkout
- Paystack live payments
- Admin: add/delete products (image via URL link)
- Promote users to admin from the site
- Orders list after payment

## Firebase
- Collection: `pratikal_products`, `users`, `pratikal_orders`
- Enable Email/Password Auth + Firestore
- Owner email is auto-admin: mabayojetemilola@gmail.com
